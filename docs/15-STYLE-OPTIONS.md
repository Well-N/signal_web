# 首页风格候选

## 共同方向

以 Hermes 的高饱和钴蓝和白色对比为基准，加入一幅钴蓝刻印的维特鲁威人、细刻线、同心轨道和细电路线。保持蓝白两色为主，不引入紫色渐变。目标是古典雕塑的庄重感加赛博朋克的精密感，界面仍然要好读。

三张图都是 1440 x 900 的 APP 首页概念稿，放在 design-previews/。主图是文艺复兴风格的维特鲁威人刻印，按首页钴蓝重新上色：黑底转成页面底色，刻线做成冰白色。源文件是 assets/vitruvian-blue.png，带透明通道。

## 方案一：钴蓝信号

文件：design-previews/01-cobalt.png

- 全屏钴蓝底。
- 左侧超大衬线标题，右侧钴蓝刻印的维特鲁威人，四周溶进同一片蓝色。
- 下方是一整条浅色信号账本。
- 最接近 Hermes 的视觉冲击，适合做品牌首页。
- 风险：整页蓝色面积大，长时间阅读需要用浅色账本区缓冲。

## 方案二：Marble Ledger

文件：design-previews/02-marble-ledger.png

- 上半部分左右分栏：左侧大理石纸面阅读区，右侧钴蓝面板里放同一张刻印。
- 标题使用中文宋体感的高对比衬线。
- 下方信号账本保持白纸和细线。
- 阅读最舒服，最像可以每天打开的产品。
- 风险：视觉冲击比钴蓝信号略低，但更适合正式 APP 首页。

## 方案三：徽章

文件：design-previews/03-medallion.png

- 深钴蓝底，中央一枚巨型圆形徽章，刻印收在圆内。
- 白色衬线标题、细网格和半透明账本。
- 更沉静，像一面夜间运行的信号屏。
- 风险：蓝色更深，信息对比度需要靠白色账本和更大字号维持。

## 推荐

如果优先像 Hermes，选钴蓝信号。

如果优先长期使用和阅读效率，选 Marble Ledger。

如果想让产品更像一块安静的信号屏，选徽章。

我的推荐是 **Marble Ledger 的结构 + 钴蓝信号的右侧刻印和蓝色冲击**：左侧保留浅色阅读纸面，右侧做全钴蓝刻印区，下方继续用信号账本。这样既有古典的庄重感，也不会让每天看资讯变成看霓虹海报。
