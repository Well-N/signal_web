# Windows 安装包

## 用户安装流程

1. 运行 `SignalWeb-Setup-0.1.5-x64.exe`。
2. 阅读欢迎页，选择仅为自己安装或为所有用户安装。
3. 通过安装位置页面填写目录或点击浏览选择目录。
4. 勾选或取消“创建桌面快捷方式”。
5. 安装完毕后，可勾选启动 SignalWeb。
6. 首次启动进入设置页，填写自己的模型服务与 API Key。

安装包包含 Electron、网页服务、Python 和采集依赖。应用不要求用户预先配置开发环境。桌面快捷方式和开机启动是独立选项；安装不会自动开启开机启动。

## 文件位置

- 程序：用户在安装向导选择的位置。
- 配置：`%APPDATA%/SignalWeb/settings.json`。
- 后端与新闻数据：`%APPDATA%/SignalWeb/pipeline/`。
- 启动日志：`%APPDATA%/SignalWeb/startup.log`。
- API Key：Windows 凭据管理器。
- PDF：设置页中用户选择的日报保存目录。

首次启动从安装资源初始化后端代码和公开配置。已有用户配置和生成的新闻不会被覆盖。安装包不包含开发者的凭据、历史新闻或演示新闻。

## 构建

在 Windows x64 上准备开发依赖，然后在 `desktop` 目录运行：

    npm ci
    npm run dist:win

`dist:win` 依次构建网页、整理运行资源、从 Python 官方下载指定版本的嵌入式运行环境并验证校验和、安装 Python 依赖，然后生成 NSIS 安装包。任一步失败即终止构建，不切换运行环境或下载源。

需要已安装 `web` 的依赖，以及 `pipeline/.venv/Scripts/python.exe` 构建环境。终端用户不需要这些工具。

输出目录：`desktop/dist/`。入口脚本：`desktop/scripts/package-win.cjs`。安装向导配置：`desktop/package.json`、`desktop/build/installer.nsh`。

## 手动验收

- 欢迎页和按钮显示简体中文。
- 可在安装位置页面选择含空格和中文的目录。
- 勾选和取消桌面快捷方式选项后均可进入安装步骤。
- 只在隔离测试环境完成安装，检查对应快捷方式是否创建。
- 在没有系统 Python、Node.js 的环境中启动，确认能打开设置页和测试模型连接。
- 验证日报生成、PDF 导出和升级后的用户数据保留。
