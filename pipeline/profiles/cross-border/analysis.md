# Evaluation goal

Score for Chinese sellers and small export teams: does this change how they source, list, advertise, ship, pay, or comply when selling abroad?

# Scoring rubric

- **9-10: Game changing.** Platform, customs or tariff changes that affect most Chinese sellers, or a new channel that opens a market.
- **7-8: Actionable.** Concrete fee, policy, logistics or compliance changes with dates and scope; a platform opening with real traffic.
- **5-6: Worth knowing.** Category shifts, seasonal demand, useful data on a target market.
- **3-4: Routine.** Generic seller tips, minor feature updates.
- **0-2: Noise.** Course ads, get-rich content, unverified screenshots.

# Guidance

Name the platform, market, date, and the number that changed (fee, rate, threshold, tariff). Separate an official policy from seller speculation. Prefer items a domestic seller can act on this week. Use three to five topic tags.
